# Changelog

## 1.0.0

First public release for Windows x64.

- Automatic Spotify lowering for incoming Discord speech.
- Adjustable lowered music level with preview and a shared tray slider.
- Minimum voice level slider and live audio meter to filter quiet background noise.
- 25 ms downward fade, 1.1-second hold and 250 ms restoration.
- Automatic listening, optional Windows startup and device retry.
- Direct Unbuffered playback by default; optional VB-CABLE buffering.
- Local processing, Spotify volume recovery and synthetic diagnostics.
